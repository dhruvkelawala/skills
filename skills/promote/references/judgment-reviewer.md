# Judgment lens

Apply the shared review contract supplied by the parent to the selected transcript and pinned boundary. Find the durable principle behind a correction: what decision should the next agent make differently?

Look for mistaken assumptions about requirements, ownership, scope, or workflow; a human intervention that changed the plan; or an agent revising an earlier conclusion after contrary evidence. Explain why the original decision failed and where the invariant belongs. Skill execution or delegation friction counts only when an actual correction demonstrates it.

Generalize enough to survive changed paths and versions, but retain a recognizable trigger and consequence. Separate judgment-dependent lessons from mechanically enforceable constraints. Return candidates in the shared contract's format; a correct decision or a principle already followed is not a finding.
